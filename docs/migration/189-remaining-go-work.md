- **Snapshot actuals follow every Go advance save (2026-11-24):** Django's `apps.budget.signals` projects an activity's advances into its current cost snapshot whenever an advance is saved; Go now does the same inside the same transaction (`gateway_day_money.project_actuals`), from the accountability and the week's advance sync. - **Accountability for several advances, an intended difference (2026-11-24):** Django's accountability view stamps one NetSuite code on every disbursed advance of the activity, but `uniq_advance_accountability_netsuite_id` lets a code clear only one advance, so on an activity with two or more advances Django submits the first and fails with "Something went wrong" on the second (reproduced on a copy).
