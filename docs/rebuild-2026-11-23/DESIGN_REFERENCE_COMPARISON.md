# Design reference comparison

| Reference | Page | Result | Intentional differences |
|---|---|---|---|
| 1 | Cluster desktop | Same structure and card order | Not Assessed instead of 0.00; no landscape banner image |
| 2 | School desktop | Same structure | Placeholder for the photo; real tab names from the brief; FY and Period filter row kept |
| 3 | School Core tab | Banner, KPIs and cards | Cards Go has no data for are not drawn |
| 4 | Route desktop | Same three columns, KPIs and bottom row | No Terrain, no invented traffic or road colours |
| 5 | Route phone | Map, filters, sheet, actions | Page header kept above the KPIs |
| 6 | School phone | Header, action row, cards | KPIs two across for legibility; trend and GPS stacked |

Comparison was by eye against screenshots from the running app. No pixel-difference tool was used.
