One table for the Admin's Platform Operations view and the Country Director's Operations view. CCEOs fold under their Program Lead, everyone else under their role, so a country roster reads as a dozen groups and not a hundred rows; a group opens by itself when somebody in it is online. Sign-ins (owner, 2026-09-16) is each person's own column: when they last signed in and how many times, which the header only had as a country total. It is not the Duration column — that is the sitting, which keeps growing after the sign-in that started it. With `staff_links` the cell links to that person's user record, where their history lives; the Country Director's copy of this table leaves it as plain text, because the admin panel is not theirs to open. Expects `presence` (apps.accounts.presence.presence_summary). With `presence_scope_label` the caption says whose roster this is: the Programme Lead's copy holds their reporting line only (owner, 2026-09-22), and every number in it counts that team rather than the country. {% endcomment %}
