{% comment %} Analytics workspace sub-navigation. Included by each Analytics section page BELOW its filter bar, so the strip belongs to the page rather than floating above its header, and guarded with `in_analytics_workspace` so it appears only where there is somewhere to switch to. Built from `analytics_sections` (apps/core/navigation.build_analytics_sections). Real links to real routes, so deep links, permissions and the browser's back button all keep working. They deliberately carry no tab roles: cross-route links are not tabs, and describing them as such would mislead a screen reader. They share the platform's tab look because that look is now one design, not because they are tabs. {% endcomment %} {% if in_analytics_workspace %}
