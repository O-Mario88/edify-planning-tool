{% comment %} The confirmation for a save that does NOT leave the page. Owner, 2026-09-18: "When I schedule it opens my plan immediately upon saving. For me to continue planning, I have to go back to the planning page... I want it to populate my plan without necessarily opening my plan, so the user can keep planning until they are done and then open My Plan to confirm." So the drawer closes, the list behind it refreshes, and this says what landed where. It carries the link rather than following it: the planner decides when they are finished, which is the whole point. Appended out-of-band into the toast container in base.html, because the Django messages framework paints its toasts on a page load and this flow deliberately has none — a queued message would surface on whatever page the planner opened next, long after it stopped meaning anything. {% endcomment %}
