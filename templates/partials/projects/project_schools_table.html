Loaded only when the card is opened, the same way the cluster card loads its roster, so a portfolio of twenty projects is one page of headers rather than twenty school tables nobody asked for. The rows are `apps.projects.portfolio.portfolio_rows` — the same reading the project profile shows, so the card and the profile cannot disagree about where a school's planning has reached. Both row actions stamp the project on the work (2026-09-24): Schedule carries the project into the scheduling drawer, and Assign (the Partner button where it is the row's only action) opens the project handover (/projects/planning/bulk-partner) rather than the generic school-support drawer, which files a handover with no project and so never reached this project's planning, monitoring or impact rows. The card is a glance, so it holds the first twelve and sends the rest to the profile. A pager would not work here: this fragment is fetched into an open card, and the shared pager's plain page links would navigate the whole page away from it. {% endcomment %}
