The workbook carries the same columns from the same rows (apps.projects.school_table), so the file is the screen. One piece of work speaks for the school — the next thing planned, else a handover still with its partner, else one handed back, else the latest work done — and with none the school is Awaiting Project Coordinator Action. What the cells say: SSA Intervention General for a project no SSA intervention measures (Alumni). Previous / Current the school's confirmed score in that intervention when it joined the project, and its latest confirmed score since. Improvement is Current less Previous, and is empty until both exist: green where the score rose, red where it fell, neutral where it did not move. Planning Stage "Awaiting {Partner Name}" while a Partner holds the work undated. Planned By the Partner once the Partner has scheduled it; the staff member who planned it otherwise. Activity Status Scheduled, Rescheduled, Completed or Cancelled. Activity Cost the activity's planned cost, once it is scheduled. Nineteen columns scroll sideways as one table; none is frozen (owner, 2026-10-02, of the consolidated tables). The coordinator's table opens with a tick column (owner, 2026-10-05: "use checkboxes on the left to check all the project schools to be assigned to the partner"): the box in the heading ticks every school on the page, and the page's Assign bar comes up once one is ticked. A school no partner may take — a Champion school, a closed one — has no box. The page holds what is ticked (`selected`, Project Monitoring's root). The school's name opens the row's details: who added it, the impact engine's verdict and its focus SSA readings. View opens the school's project work in a drawer. Everyone but the Project Coordinator reads; the coordinator's doors (Schedule, Assign to a partner, Withdraw/Reassign, Resolve) are drawn for them alone on Project Monitoring, in the row's Actions menu beside View, and checked again by each drawer's route and by the service behind it. `view_only` draws View alone (Planning Oversight's Special Projects tab). {% endcomment %}
