{% comment %} "Select all" for a list of tick boxes (owner, 2026-10-05: "all the places with checkboxes can you add Select All Checkbox"). It ticks every enabled box that can be seen in its scope: the nearest [data-select-scope], else the table, fieldset or form it sits in (static/js/group-select.js). Each box gets its own change event, so a list bound to Alpine keeps up, and the box reads back ticked, part-ticked or clear as the list changes. `boxes`: a selector that names the boxes, where the scope holds other lists too. `label`: the words, "Select all" by default. {% endcomment %}
