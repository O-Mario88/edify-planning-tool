{% comment %} What this organisation does — interventions, and the activities under them. Owner, 2026-09-22: "Some partners are doing more than one activity. Can you make sure the list of interventions and their activities are in checkbox so that many activities can be assigned to partners." One dropdown could hold one answer, so a partner running literacy training and financial-health coaching was recorded as running one of them. This is a tick-list instead, built from the live catalogue by `apps.partners.capabilities`: each SSA intervention, and under it the catalogue activities a partner may actually be given (`partner_delivery_allowed`). An intervention can be ticked on its own — an organisation may cover a whole intervention before the catalogue has a named activity for it. Ticking any activity ticks its intervention too, because an organisation delivering the work covers the intervention by doing so; that is done here rather than on save, so the form shows what it is about to record. Expects `capability_groups`, `selected_interventions`, `selected_activities`. {% endcomment %} {% comment %}The two handlers below match on `dataset` rather than building a CSS selector, because a group key can hold a colon and an attribute selector would need a quote this attribute cannot carry.{% endcomment %}
